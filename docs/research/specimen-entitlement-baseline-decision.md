# Entitlement baseline decision

Current status: [overnight entitlement handoff](overnight-entitlement-handoff.md). This report preserves its
original experiment history; later acceptance and persistence results are linked from the handoff.

The native component boundary is viable for loading the real library, but is not yet coherent enough for an
ordinary installer trial. The first call to the stock factory faults before service inventory or identity setup.
There is no option-state baseline to compare with an installation, so an installer trial would be premature.

The next bounded question is the missing factory caller/runtime prerequisite. Recover the stock caller and
callback setup statically, then obtain a precise native fault location if necessary. The prior exception path
lost that location. A diagnostic run must not also add speculative callbacks, hardware values or successful
service responses; any correction follows its own evaluation.

This takes priority over recovering more deterministic ADC operations or booting the complete captured board
image. It directly tests whether the short native path can support ordinary option handling. Runtime DNA and
external private-store contents remain separate known gaps; they were not dynamically reached in this run.
If a genuine physical dependency blocks one branch, retain its exact bench question and pursue useful offline
work under the overnight authorization. No specimen connection or modification is part of the continuation.
