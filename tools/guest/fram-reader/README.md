# Bounded FRAM reader

`read-fram DEVICE EXPECT_MAJOR EXPECT_MINOR OUTPUT_DIRECTORY` requires absolute device and new output-directory paths. Major and minor are decimal. The caller must independently bind this node and adapter to the live stock CFram descriptor and bracket that binding. This wrapper only checks the opened descriptor's character-device type and expected device number; it does not infer the adapter or process owner.

The fixed acquisition is two sequential 8192-byte images, using 512 combined transactions each. Each transaction uses address `0x50`, a two-byte big-endian selector followed by a 16-byte read in one `I2C_RDWR` ioctl. Only return value exactly 2 commits the page. No force-address ioctl, data-write operation, or automatic retry exists. Device opening is read/write because the combined transaction includes the address selector; the only device syscall after validation is the fixed combined ioctl.

`transactions.bin` is an append-only sequence of 64-byte little-endian records: round (u64, zero-based), offset (u64), raw syscall return (i64), errno (u64, zero for nonnegative returns), selector (2 bytes), scratch (16 bytes), reserved zero bytes (14). Scratch is preserved even on short return or error; it is not thereby valid acquired data. Every record is written and fsynced before continuing. An evidence-write failure stops acquisition and may leave a partial journal record; never interpret that partial record as complete.

`image-1.bin` and `image-2.bin` contain only each attempted image's completed prefix. An unattempted image has no file. The manifest records exact completed lengths. Differing complete images are preserved and rejected; equality establishes neither atomicity nor persistent-state consistency. Maximum acquisition is 1024 ioctls, 16384 returned data bytes and 2048 selector bytes. There is no retry, recovery, or device execution in the build script.

Build with `build.py --cc CLANG --ld LLD --host-cc HOST_CC --output OUTPUT`. It compiles a freestanding Linux ARM64 executable and exercises that same wrapper through host syscall injection, including character/device-number rejection, short transfer, failed transfer, and differing images. The host controls never open a device. `build.toml` records compiler and artifact hashes. The header is unchanged from `tools/guest/fram-contract/fram-read.h`.
